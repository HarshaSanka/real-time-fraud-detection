# Scoring API contract

The OpenAPI 3 contract is generated by FastAPI at `/openapi.json`; interactive documentation
is served at `/docs`. Public objects carry schema version `1.0`.

## TransactionEventV1

Required fields are a synthetic transaction, customer and merchant ID; timezone-aware UTC
timestamp; positive amount; USD currency; merchant category; and valid merchant latitude and
longitude. Optional customer-home coordinates, state, and city population enable additional
context. Unknown merchant categories must be the explicit `other` value. Card numbers, PANs,
CVVs, names, addresses, and credentials are not accepted.

```json
{
  "schema_version": "1.0",
  "transaction_id": "txn_98373",
  "customer_id": "cust_1021",
  "merchant_id": "merchant_92",
  "timestamp": "2026-08-12T14:32:10Z",
  "amount": 2750.0,
  "currency": "USD",
  "merchant_category": "shopping_net",
  "merchant_latitude": 41.8818,
  "merchant_longitude": -87.6231,
  "customer_home_latitude": 41.8781,
  "customer_home_longitude": -87.6298,
  "customer_state": "IL",
  "city_population": 2746388
}
```

## ScoreResponseV1

```json
{
  "schema_version": "1.0",
  "transaction_id": "txn_98373",
  "fraud_probability": 0.931,
  "risk_level": "HIGH",
  "decision": "BLOCK",
  "model_version": "fraud-random_forest-20260812225357",
  "threshold_version": "business-policy-v1",
  "latency_ms": 21.0,
  "reason_codes": ["AMOUNT_ABOVE_CUSTOMER_BASELINE"],
  "degraded_mode": false
}
```

The exact model version changes after an approved promotion. Probabilities are calibrated and
thresholds are versioned independently. A repeated transaction ID returns its persisted first
decision. Batch input uses `{"transactions": [...]}` and is capped at 100 events.

## Failure semantics

| Condition | Result |
|---|---|
| Invalid field, category, timestamp or amount | 422; never scored or persisted |
| No valid model bundle | `/ready` and scoring return 503 |
| Redis unavailable | score with history missing; minimum decision is REVIEW |
| Duplicate transaction ID | return the original idempotent prediction |
| Kafka unavailable after API score | prediction/outbox remain committed; publication retries |
| Corrupt Kafka payload | sanitized DLQ event; model is not invoked |
| More than 100 batch events | 422 |

Logs and metrics contain bounded route/status/decision/model labels. They do not include raw
customer IDs, transaction amounts, location coordinates, or request bodies.
